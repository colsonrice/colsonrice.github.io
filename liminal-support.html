Liminal · For fiction writers

Getting started with Liminal

Help with your writing space, coaching, and manuscript.

Start writing for free

Create a story, add your notes, and start writing. Writing, saving, importing, and exporting do not need an API key or a subscription.

Connect your OpenAI account

  1. Open OpenAI API keys and create a key for your own account. Set up API billing and spending controls there.
  2. In Liminal, open Settings and save the key under Your OpenAI key. It is stored in your Mac's Keychain.
  3. Read the Cost and Your words sections. Online requests are billed by OpenAI, including automatic readings when enabled.

Never email your key. If a key is exposed, revoke it in OpenAI and replace it in Liminal. Choose the app's Free mode to stop OpenAI requests. A ChatGPT subscription and API usage are separate services.

Protect and export your work

Keep a backup from Settings > Everything before moving to a new Mac. Use Review & export for Word, PDF, and text copies. File > Restore an earlier version lets you inspect a saved version before restoring. Local history is not a substitute for a separate backup.

If coaching cannot connect

Check your internet connection, API key, OpenAI billing, and model access. You can keep writing and exporting while coaching is unavailable. The message beside the affected tool explains what needs attention.

Contact SquatchCraft

Email hello@squatchcraft.com with your macOS version, Liminal version, what you tried, and the error message. Send a small example only if you are comfortable sharing it. Do not include API keys or a private manuscript.
